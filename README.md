# ผู้ช่วยตารางสอน (Schedule Chatbot) — อาจารย์ไมตรี นาโพธิ์

แชทบอทตอบคำถามตารางสอนของ **อาจารย์ไมตรี นาโพธิ์** เท่านั้น (วิทยาลัยเทคนิคสัตหีบ)
ไม่ว่าจะถามอะไรมา ระบบจะตอบโดยอิงข้อมูลของอาจารย์ท่านนี้เท่านั้น — ถ้าถามเรื่องอื่นจะบอกตรงๆ ว่าไม่มีข้อมูล
(Node.js + Express backend, Vue 3 frontend, Google Gemini API เป็นตัวตอบคำถาม — ใช้ฟรีได้)

## โครงสร้างโปรเจกต์

```
schedule-chatbot/
├── data/
│   ├── schedules.json     ← ข้อมูลตารางสอนของอาจารย์ไมตรี นาโพธิ์ (ใช้จริง)
│   └── raw/page_007.json   ← ข้อมูลดิบจากหน้า PDF ต้นฉบับ (เก็บไว้อ้างอิงเท่านั้น)
├── backend/                 ← Node.js + Express API
│   ├── server.js
│   ├── routes/api.js
│   └── lib/{data,retrieval,llm}.js
└── frontend/                ← Vue 3 (Vite)
    └── src/App.vue
```

## ข้อมูล (data/schedules.json)

ไฟล์นี้มีข้อมูล **อาจารย์ไมตรี นาโพธิ์คนเดียว** — ชื่อ แผนกวิชา วุฒิการศึกษา หน้าที่พิเศษ
รายวิชาที่สอน และตารางสอนรายคาบ (วัน/เวลา/ห้อง/กลุ่มเรียน) ถอดมาจากหน้า 7 ของ PDF ต้นฉบับ
เก็บรูปแบบรหัสวิชา/เวลา/กลุ่มเรียนตามต้นฉบับ (เช่น `31901-2007`, `08:00`, `สท.4/1-2`)

## ติดตั้งและรัน

ต้องมีอินเทอร์เน็ต (เพื่อ `npm install`) และ Node.js 18+ บนเครื่องที่จะรัน

### 1) Backend

```bash
cd backend
npm install
cp .env.example .env
# แก้ .env ใส่ GEMINI_API_KEY=... ของคุณ (ขอฟรีได้ที่ https://aistudio.google.com/apikey)
npm start
# รันที่ http://localhost:3001
```

### 2) Frontend

```bash
cd frontend
npm install
npm run dev
# เปิด http://localhost:5173
```

Vite dev server มี proxy `/api` -> `http://localhost:3001` ให้อยู่แล้ว (ดู `vite.config.js`)
ไม่ต้องตั้งค่าอะไรเพิ่มถ้ารันสอง server พร้อมกันตามค่า default

### Build เป็นไฟล์ static (โปรดักชัน)

```bash
cd frontend
npm run build     # ได้ไฟล์ใน frontend/dist/
```
แล้วเสิร์ฟ `frontend/dist/` ด้วย web server ใดก็ได้ (nginx, serve, หรือให้ Express เสิร์ฟเป็น static ก็ได้)
โดยตั้ง `VITE_API_BASE` ให้ชี้ไปที่ URL จริงของ backend ก่อน build

## API หลัก (backend)

| Method | Path | คำอธิบาย |
|---|---|---|
| GET | `/api/health` | เช็คว่า server รันอยู่ |
| GET | `/api/teacher` | ข้อมูล+ตารางสอนเต็มของอาจารย์ไมตรี นาโพธิ์ |
| GET | `/api/teachers/search?q=ไมตรี` | ค้นหาชื่ออาจารย์ (มีคนเดียวในระบบ) |
| GET | `/api/periods?day=จันทร์&room=COM602` | ค้นหาคาบเรียนแบบกรองเงื่อนไข |
| POST | `/api/chat` | ส่ง `{message, history}` รับคำตอบจาก Gemini |

## ระบบตอบคำถาม (chatbot) ทำงานอย่างไร

1. ผู้ใช้พิมพ์คำถามเป็นภาษาธรรมชาติ (เช่น "วันนี้อาจารย์ไมตรีสอนอะไรบ้าง")
2. Backend (`lib/retrieval.js`) แนบข้อมูลตารางสอนทั้งหมดของอาจารย์ไมตรี นาโพธิ์ (มีแค่คนเดียว
   ในระบบ ข้อมูลมีขนาดเล็ก จึงส่งทั้งหมดได้โดยไม่ต้องกรอง) พร้อม**วันที่/เวลา/วันในสัปดาห์ปัจจุบัน
   ของไทย** (field `now`) ไปพร้อมกับคำถาม เพื่อให้ตอบคำถามแบบสัมพัทธ์ได้ เช่น "วันนี้" "พรุ่งนี้"
   "เมื่อวาน" "ตอนนี้สอนอยู่ไหม"
3. ส่งให้ Gemini API (`lib/llm.js`) พร้อม system prompt ที่กำชับว่า **ไม่ว่าจะถามอะไรมา
   ให้ตอบโดยอิงข้อมูลของอาจารย์ไมตรี นาโพธิ์เท่านั้น** ห้ามเดา ห้ามพูดถึงคนอื่น และให้คำนวณ/สรุป
   คำตอบเองจากข้อมูลดิบ (นับจำนวนคาบ/ชั่วโมง เช็กว่าง/ไม่ว่าง เปรียบเทียบระหว่างวัน ฯลฯ) แทนที่จะ
   ตอบได้แค่คำถามที่ตรงกับข้อมูลแบบคำต่อคำ
4. ถ้าคำถามไม่เกี่ยวกับตารางสอนของอาจารย์ท่านนี้เลย บอทจะบอกตรงๆ ว่ามีข้อมูลเฉพาะของอาจารย์
   ไมตรี นาโพธิ์เท่านั้น แทนที่จะตอบเรื่องอื่น

**ตัวอย่างคำถามที่ตอบได้:** วันนี้/พรุ่งนี้สอนอะไรบ้าง, วันจันทร์ห้อง COM602 มีสอนอะไร,
สอนทั้งหมดกี่ชั่วโมงต่อสัปดาห์, มีวิชาอะไรบ้าง, บ่ายวันศุกร์ว่างไหม, วันไหนสอนเยอะที่สุด,
กลุ่มเรียนไหนเรียนกับอาจารย์บ้าง ฯลฯ

## หมายเหตุสำคัญ

- ใช้ **Google Gemini API** ซึ่งมี free tier ให้ใช้ฟรี (มีโควตาจำกัดต่อวัน/ต่อนาที แต่พอสำหรับ
  ใช้งาน/ทดสอบทั่วไป) ขอ API key ฟรีได้ที่ https://aistudio.google.com/apikey (ล็อกอินด้วย Gmail)
  ไม่ต้องผูกบัตรเครดิต
- ค่าเริ่มต้นโมเดลคือ `gemini-2.0-flash` (ตั้งค่าใน `backend/.env` ด้วย `GEMINI_MODEL`) —
  ตรวจสอบชื่อโมเดลและโควตาฟรีล่าสุดได้ที่ https://ai.google.dev/gemini-api/docs/models
- โค้ดชุดนี้ถูกเขียนและตรวจ syntax/ทดสอบ logic การค้นหาข้อมูล (`scripts/test_logic.js`) แล้ว
  แต่ยังไม่ได้รัน backend/frontend แบบเต็มรูปแบบในสภาพแวดล้อมที่สร้างโค้ดนี้ขึ้นมา
  (เครือข่ายที่ใช้สร้างโค้ดเข้าถึง npm registry ไม่ได้) — รันทดสอบเต็มรูปแบบอีกครั้งบนเครื่องของคุณ
